Conversions: 1 bit = 20 C/A code periods = 20,460 chips ≈ 31.5 million carrier cycles. 1 chip = 1,540 carrier cycles. This hierarchy — coarse ruler (code) first, fine ruler (carrier phase) second — is where the layered precision of GNSS comes from.

Why multiply by a code and "spread" at all?

Sending 50 bps directly needs only ~100 Hz of bandwidth. Replacing it with a 1.023 Mcps code spreads it to ~2 MHz (spread spectrum) for three reasons.

(1) Digging the signal out from below the noise: GPS arrives at about −130 dBm, 20+ dB below thermal noise. But correlating with a replica code makes only the matching, code-aligned component pile up (processing gain 10log₁₀(1023×20) ≈ 43 dB), and a peak rises out of the noise. The correlation experiment on the Pseudorange page is exactly this.

(2) All satellites share one frequency (CDMA): each satellite has its own Gold code. Gold codes barely correlate with each other, so only the satellite matching your replica appears; the rest stay noise. A "PRN number" is the jersey number of that code.

(3) The code is a range ruler: the chip sequence is a time scale. How far the code arrives shifted is the travel time — hence the distance.

BPSK and phase — the link back to Wave Basics

BPSK (binary phase-shift keying) sends the carrier as-is for +1 and phase-inverted 180° for −1. In zoom ③ you can see the wave snap at chip boundaries. The "phase" you played with in the Wave Lab is working here as a switch that carries information.

The receiver removes these flips (by re-applying the code), recovers the clean carrier, and tracks its phase with a PLL. The carrier wavelength is 19 cm — reading that phase is the doorway to cm-level positioning like RTK.

How do GPS and QZSS differ here?

For L1 C/A, this structure is identical on GPS and QZSS. The only difference is which Gold code: GPS uses PRN 1–32, QZSS uses PRN 193–202. A receiver can treat QZSS as "GPS satellites #33 and up" with no software change — the heart of QZSS's compatibility-first design.

On the same L1 frequency, the newer L1C signal (CNAV-2) uses fancier BOC modulation. See the Navigation Messages page for how the message formats differ too.
