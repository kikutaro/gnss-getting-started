## What is this?

To be honest, I’m a newbie when it comes to GNSS. But I need to keep studying. Since there’s so much to learn, I launched this “GNSS Getting Started” project in the hope of creating learning materials together with Claude Code.

If you find any errors in the content, please point them out in an issue.
